================================================================================
                    NutriPal 项目技术总结
                    终端 AI 营养师 v1.0
================================================================================

【项目定位】
  一个运行在 Windows 终端里的 AI 营养师。用户通过自然语言告诉它冰箱里有什么、
  身体目标是什么，它基于 DeepSeek V4 Pro 大模型给出带营养学分析的膳食方案。
  支持减肥食谱推荐（含分时段安排、份量、克数）。
  双击 NutriPal.exe 即可运行，无需安装任何环境。


================================================================================
  一、技术栈
================================================================================

  [语言]        Python 3.11
  [AI 大模型]    DeepSeek V4 Pro（通过官方 API，OpenAI 兼容协议）
  [API 通信]     OpenAI Python SDK（自定义 base_url 指向 DeepSeek）
  [终端 UI]     Rich 13.x —— 彩色输出、Panel 面板、Table 表格、流式渲染
  [终端输入]    prompt-toolkit 3.x —— 历史记录、样式化提示符、非 TTY 回退
  [数据建模]    Pydantic 2.x —— 类型校验、字段约束、BMR/TDEE 计算模型
  [数据持久化]  本地 JSON 文件（profile.json / fridge.json / history.json）
  [打包分发]    PyInstaller 6.x —— onedir 模式，生成独立 .exe
  [版本控制]    Git + GitHub

  二、架构设计（分层架构）

  main.py                    入口 + 路径解析（开发/打包自适应）
    └── nutripal/app.py      主应用 REPL 循环（启动 -> 问卷 -> 对话循环）
          ├── nutripal/data/      数据层
          │     ├── models.py     Pydantic 数据模型（Profile/Fridge/MealPlan）
          │     └── store.py      JSON 文件存储（增删改查 + 合并去重）
          ├── nutripal/api/       API 层
          │     └── client.py     DeepSeek 客户端（8 个 Tool Function + 流式输出）
          ├── nutripal/ui/        UI 层
          │     ├── console.py    Rich 终端渲染（Banner/表格/Fridge/Profile）
          │     └── input_handler.py  prompt_toolkit 输入（历史 + 回退）

                └── chat.py           对话编排（上下文注入 + Function Loop）


================================================================================
  三、核心功能清单
================================================================================

  [1] 自然语言智能意图识别
      - 基于 DeepSeek Function Calling，用户无需记忆任何命令
      - 8 个 Tool Functions 定义发送给 AI，AI 自动判断用户意图
      - 示例："鸡蛋吃完了" -> AI 调用 remove_from_fridge("鸡蛋")
      - 示例："我胖了2斤" -> AI 调用 update_profile("weight_kg", "76")

  [2] 虚拟冰箱管理
      - add_to_fridge    添加食材（支持同名合并："3个鸡蛋" + "2个鸡蛋" = 5个）
      - remove_from_fridge  移除食材
      - view_fridge      查看库存（Rich 表格渲染）
      - clear_fridge     一键清空

  [3] 用户身体档案管理（长期记忆）
      - update_profile   更新身高/体重/年龄/性别/活动水平/目标
      - view_profile     查看档案（含每日推荐摄入 kcal）
      - 基于 Mifflin-St Jeor 公式计算 BMR
      - 基于活动水平计算 TDEE
      - 基于目标（减重 -500 / 增肌 +300 / 保持）计算目标热量

  [4] 首次启动问卷（Onboarding）
      - 7 题逐一询问：身高、体重、年龄、性别、活动水平、目标
      - 每题带范围验证（身高 100-250cm，体重 20-300kg，年龄 1-120）
      - onboarding_complete 标记，后续启动自动跳过
      - 支持 Ctrl+D / Ctrl+C 优雅退出

  [5] 膳食方案生成
      - generate_plan    基于冰箱食材 + 用户目标生成方案
      - 输出包含：分时段（早/午/晚/加餐）、菜品名称、食材克数、
        热量 (kcal)、蛋白质 (g)、碳水 (g)、脂肪 (g)
      - 减肥场景可输出每周食谱框架和进餐时间建议

  [6] 历史记录
      - view_history     查看最近 5 条历史膳食方案
      - history.json     持久化存储

  [7] 流式输出
      - AI 回复逐 token 显示，不等待完整响应
      - 基于 DeepSeek API 的 SSE 流式协议

  [8] 对话管理
      - 多轮对话历史（保留最近 20 轮）
      - 上下文自动注入（身体档案 + 冰箱库存作为 System Prompt）
      - 数据变化后自动刷新 System Prompt
      - Function Call 循环（最多 3 轮，防止死循环）

  [9] 容错与健壮性
      - Unicode 兼容：所有 emoji 替换为 ASCII（兼容 Windows GBK 控制台）
      - Rich 控制台：force_terminal=True 绕过旧版 Win32 控制台 API
      - 网络异常：API 调用失败显示错误但不退出
      - EOF 处理：Ctrl+D 优雅退出
      - 输入回退：prompt_toolkit 不可用时自动降级为 input()

  [10] 打包分发
      - PyInstaller onedir 模式
      - 双击 NutriPal.exe 即可运行
      - config.json 和 data/ 目录与 exe 同级，用户可直接编辑
      - 重新打包时保留已有 API Key


================================================================================
  四、数据流转示意
================================================================================

  用户输入自然语言
       │
       ▼
  ChatManager.process()
       │
       ▼
  DeepSeekClient.chat(messages + Tools)
       │
       ├── AI 返回 function_call ──> commands.execute_function_call()
       │         │                          │
       │         │                    DataStore 更新 JSON
       │         │                          │
       │         └──── 结果反馈给 AI ◄────────┘
       │                   │
       │              AI 生成自然语言回复
       │
       └── AI 返回纯文本 ──> 流式输出到终端（Rich Console）


================================================================================
  五、JSON 数据模型
================================================================================

  profile.json:
    height_cm, weight_kg, age, gender, activity_level, goal,
    onboarding_complete, created_at, updated_at

  fridge.json:
    items: [{ name, quantity, unit, added_at }]

  history.json:
    plans: [{ id, date, type, goal, meals: [{ time, name, items,
              total_calories, protein_g, carbs_g, fat_g }],
              daily_summary }]
